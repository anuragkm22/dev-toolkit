About Dev Toolkit

Dev Toolkit is a small collection of focused utilities for developers and data engineers — starting with the Config Diff & Validator, a tool for comparing JSON and YAML config files without getting distracted by key reordering or formatting noise.

Everything on this site runs entirely in your browser. There's no backend, no account, and no data storage — what you paste into a tool stays on your machine and is never sent anywhere.

More tools are on the way. This page will grow along with the site.
